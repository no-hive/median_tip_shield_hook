PFPHook is a Uniswap Hook project. This page introduces the core concept and serves as the entry point to the documentation.

> **PFPulse Hook = Priority Fee Pulse Hook.**

## Why PFPHook

<CardGroup cols={3}>
  <Card title="Median Oracle" color="#FF007A" icon="activity">
    A shared, on-chain pulse of priority-fee activity that stays calibrated even for thin pools.
  </Card>

  <Card title="Dynamic Fees" color="#FF007A" icon="bug-off">
    Adaptive swap fees that make MEV bots pay for the block space they try to steal.
  </Card>

  <Card title="On-Chain Only" color="#FF007A" icon="bow-arrow">
    No off-chain oracles and no trusted operators. All logic lives inside the Hook.
  </Card>
