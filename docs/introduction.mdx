## Overview

**MPF Hook** is a Uniswap v4 hook that shields liquidity providers from MEV extraction. Instead of watching prices or trade sizes, it watches how aggressively users bid on priority fees, and charges an adaptive swap fee whenever a transaction looks like front-running.

Collected fees are redistributed to LPs, turning MEV pressure into compensation.
