## Prerequisites

- [Foundry](https://book.getfoundry.sh/) installed
- Node.js v18+ and a package manager
- An EVM RPC endpoint (Ethereum, Base, Arbitrum, or a testnet)
- A funded deployer wallet

## Install

Clone the repository and install dependencies:

```bash
git clone https://github.com/no-hive/median_tip_shield_hook.git
cd median_tip_shield_hook
forge install
