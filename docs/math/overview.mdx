This section contains a detailed walkthrough of the calculation choices used by PFPHook.

Its materials explain the mathematical decisions behind the Hook and are intended to help developers adapt the Hook's code to their own requirements. Using these references, developers can deploy a pool grid with comparable protection properties while applying different mathematical models or parameter choices.

This overview page provides the global explanation of the module, its calculation flow, key design decisions, terminology, assumptions, and relationships between the mathematical components.
